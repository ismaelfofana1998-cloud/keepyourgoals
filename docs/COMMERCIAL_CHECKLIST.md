# Checklist de commercialisation

## Produit
- [ ] parcours d’inscription testé ;
- [ ] onboarding testé sur mobile et ordinateur ;
- [ ] données de démonstration préparées ;
- [ ] quotas et messages de dépassement validés ;
- [ ] exports et suppression de compte définis ;
- [ ] support et procédure de récupération définis.

## Paiement
- [ ] produits Stripe créés ;
- [ ] prix test et live séparés ;
- [ ] taxes configurées ;
- [ ] portail client configuré ;
- [ ] paiements réussis, échoués et résiliations testés ;
- [ ] politique de remboursement publiée.

## Juridique
- [ ] société éditrice renseignée ;
- [ ] CGU/CGV validées ;
- [ ] politique de confidentialité validée ;
- [ ] registre des sous-traitants ;
- [ ] base légale et durées de conservation ;
- [ ] procédure d’exercice des droits.

## Exploitation
- [ ] domaine personnalisé et HTTPS ;
- [ ] sauvegardes ;
- [ ] supervision ;
- [ ] alertes de coûts Groq/OpenAI/Supabase/Stripe ;
- [ ] plan de réponse aux incidents ;
- [ ] environnement de staging.
